# 🎰 PixelCasino

Красивое пиксельное (chiptune) казино **для развлечения**. Виртуальные кредиты, никаких реальных денег.

## Как запустить

Просто откройте `index.html` в браузере (двойной клик). Всё работает без сборки и без интернета (шрифты подгружаются из сети, но есть системный fallback).

> Звук включается после первого клика/нажатия (требование браузеров к Web Audio).

**Особенности:**
- 🔊 Все звуки синтезируются вживую через Web Audio API (чистый 8-бит/chiptune, без аудиофайлов) — клики, монеты, барабаны, выигрыши, джекпоты + фоновая музыка
- ✨ Плавные анимации, конфетти, дождь монет, тряска экрана при крупных выигрышах
- 💾 Прогресс (баланс, уровень, лучший выигрыш) сохраняется в localStorage
- ⭐ Система уровней с XP и бонусами
- 🎁 Бонус-кредиты, когда баланс заканчивается
- 📱 Адаптивная вёрстка

## Структура

```
index.html
css/style.css          — неон-аркадный стиль, все анимации
js/audio.js            — chiptune SFX-движок + музыка
js/core.js             — кошелёк, эффекты, тосты
js/main.js             — лобби, навигация
js/games/*.js          — по файлу на тип игры
```

Управление звуком/музыкой — иконки 🎵 🔊 в правом верхнем углу. Сброс прогресса — иконка ↻.
