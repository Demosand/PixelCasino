# 👑 Royal Palace Casino

Премиальное казино **для развлечения** — дизайн в духе дорогих заведений (золото, тёмный нуар, Cinzel). Виртуальные кредиты, никаких реальных денег.

## Как запустить

Просто откройте `index.html` в браузере (двойной клик). Всё работает без сборки и без интернета (шрифты подгружаются из сети, но есть системный fallback).

> Звук включается после первого клика/нажатия (требование браузеров к Web Audio).

- 🔊 Все звуки синтезируются вживую через Web Audio API (тёплые «колокольчиковые» тембры, мягкий мастер-фильтр и компрессор, без аудиофайлов) — клики, монеты, барабаны, выигрыши, джекпоты + спокойная лаунж-музыка

## Структура

```
index.html
css/style.css          — неон-аркадный стиль, все анимации
js/audio.js            — chiptune SFX-движок + музыка
js/core.js             — кошелёк, эффекты, тосты
js/main.js             — лобби, навигация
js/games/*.js          — по файлу на тип игры
```

Управление звуком/музыкой — иконки 🎵 🔊 в правом верхнем углу. Сброс прогресса — иконка ↻.
